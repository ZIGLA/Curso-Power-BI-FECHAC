# Curso Power BI FECHAC

Sitio del curso de Microsoft Power BI que ZIGLA class dicta al equipo de FECHAC (octubre–diciembre 2026).

- `index.html`: el sitio (no hace falta tocarlo).
- `datos.js`: **el contenido**. Para sumar la presentación, la grabación, la tarea o material complementario de una clase, se edita solo este archivo.

La grabación va como ID de un video de Google Drive compartido con "cualquier persona con el enlace" (o un enlace de YouTube).
Los materiales de cada clase se muestran desde el día de la clase; `abrir: true` los muestra antes.
